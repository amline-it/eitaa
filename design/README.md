# Amline Home Dashboard — Prototype

High-fidelity mobile UI prototype extracted from the home dashboard design mockup.

## Run locally

```powershell
cd D:\cloud-manager\prototype\amline-home-dashboard
npm install
npm run dev
```

Open: http://127.0.0.1:5178/

## Stack

- Vite + React 18
- Pure CSS (RTL, Vazirmatn font)
- Brand colors aligned with amline-platform (`#179A9C` teal)

## Sections

1. Header — logo, greeting, notifications
2. Hero banner — 3-step contract CTA with illustrations
3. Stepper — اطلاعات → امضا → رهگیری
4. Service grid — 2×2 action cards
5. Draft card — in-progress contract with progress bar
6. Bottom navigation — FAB + 4 tabs
